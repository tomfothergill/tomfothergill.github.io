# Coral floral article theme

Approved 15 September 2026 for a future article. This directory contains styling and artwork only; no unpublished article content.

Load coral-theme.css after article-layout.css and add article-page--coral alongside article-page on the body. The stylesheet uses the adjacent original scan at 440px wide for desktop strips and inherits the shared mobile ornament band.

The source download was china-vase-1-1600.jpg. Confirm the illustration attribution before using it on a published article.

Used by the hiring page and its thank-you page from 15 September 2026. The pattern URL is root-relative because the shared article stylesheet consumes the custom property. Attribution: [Floriated China Vase Design](https://www.oldbookillustrations.com/illustrations/china-vase-1/), Owen Jones, *Examples of Chinese ornament*, 1867.
