# Approved baseline — 10 September 2026

The approved article is preserved at `table-tennis/baseline.html`. Its stylesheet
links point to the copies in this directory, so subsequent styling changes do not
alter the baseline. The illustration and bet log remain shared, unchanged assets.

`render_page.py` is an archival copy of the generator before the full rewrite.
To restore it, copy it back to `build/render_page.py`, restore these stylesheets
to the repository root, and run `python build/render_page.py` from the repository
root. Do not run this archived script directly; its paths depend on its location.
